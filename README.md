# ⚙️ Marketing Analytics & Data Automation Workflows

## 💡 Resumen del Proyecto
Modelado de datos para Looker Studio y diseño de flujos de automatización operacional enfocados en monitorear la fuga de ingresos en e-commerce, alertas de carritos abandonados y optimización de presupuesto publicitario.

---

## 🚀 Arquitectura de la Solución
1. **Modelado Data Master (`master_ecommerce_looker_studio.csv`):** Estructuración de datasets limpios para integración directa con conectores de Looker Studio y Power BI.
2. **Monitoreo de Fuga Operativa:** Seguimiento de transacciones fallidas en pasarelas de pago y tasas de devolución logística por SLA de entrega.
3. **Automatización:** Integración con herramientas no-code/low-code (Make.com y n8n) para alertas automáticas en canales de equipo.

---

## 🛠 Stack Tecnológico
* **BI & Visualización:** Looker Studio, Power BI
* **Automatización & ETL:** Make.com, n8n, Python
* **Gestión de Datos:** SQL, Excel / Google Sheets
